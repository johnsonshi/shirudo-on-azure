# Shirudo on Azure

Run [Shirudo](https://github.com/shirudo-dev/shirudo), the open-source eBPF runtime from OpenAI and Cisco, on an Azure VM: a patched bpf-next kernel, boot-time BPF LSM enforcement, signed shields, and a measurement register in the Azure vTPM.

Work in progress. See `infra/`, `kernel/` and `patches/`.
